# dsh-routing-local 本地定制台账（preset）

> **本文件是 dsh-routing-local 的唯一维护参考**，权威副本在本仓 `docs/`（本机不留拷贝）。
> 只记录现状：每一项定制是什么、在哪里、怎么装、怎么验证。
> 维护原则：**仓库是全部定制的唯一真源**；preset 改动必须 bump `?v=`、重跑 `tools/build-presets.mjs`
> 并跑 selftest；同步上游前先核对第二节台账，避免重复打补丁。

- 组织参照：https://github.com/yjh051108/dsh-routing-suite
- 本机安装：preset 包（router-standard / router-spec），不含 graded
- 内核基线：`@deepseek-ai/dsh@0.2.0-rc.2`（DSH Desktop 2.0.17-next）——已核验：65 条引用全部可解析、两 preset 注册成功
- 路径约定：`<本仓>` 指本仓根目录；`<DSH 安装位>` 指 DSH Desktop 安装目录（安装器选定，即含 `resources\app\node_modules` 的那一层）。

## 一、当前形态

| 组件 | 形态 | 位置 |
|---|---|---|
| **preset 包** | github 直装，无构建步骤（入口注册两个预设） | profile 依赖：`github:Ztyss/dsh-routing-local#path:/preset` |

- profile `dsh.profile.bundles` 列 `@dsh-external/dsh-router-presets`。
- **预设注册**：`preset/lib/index.mjs` 在 `apply()` 里调 `ctx.agentPresets.register()` 注册
  `router-standard` / `router-spec`（等价于一条 `@deepseek-ai/dsh-agent-preset` 声明）；
  预设条目的 `name` 用包内子路径，映射见 `preset/package.json` 的 `exports`。
- **改动戳与热重载**：`<id>/agent.cordis.yml` 是人读源，`?v=` 是改动戳
  （当前值：std bootstrap `?v=96`、spec `?v=2`）；运行时热重载走「代」——
  `$DSH_HOME/router-presets/generation.json` 的代数进 `<实现>.mjs?gen=N`，
  `dev_reload_preset_live` 调 `bumpGeneration()` + `recompose()`。
- **状态目录**：全部收在 `$DSH_HOME/router-presets/`——`status.json`（装机自检：注册
  outcome / failed / roster）、`generation.json`（热重载代数）、`router-standard/`
  （`stages.json` 阶段状态、`last-mount.txt` 挂载标记、`bash-diag.json` bash 诊断）。
- 直装前置（全局 git 配置）：`http.sslBackend schannel` + `http.version HTTP/1.1` + gh 凭据
  （`gh auth setup-git`）——OpenSSL 栈在代理上握手会被重置。
- 直装产物 lib 自带 sourcemap，运行无碍。

## 二、本地定制台账

### preset 包外壳

| # | 定制 | 落点 | 说明 |
|---|---|---|---|
| E1 | 装配入口：`ctx.agentPresets.register()` 注册两份定义；`cordis.patch.yml` 提供宿主启动行 | `lib/index.mjs`、`cordis.patch.yml` | 宿主启动装配与插件安装触发的热装配（`loader.create`）共用同一入口 |
| E2 | 条目引用用包内子路径；插件名对齐当期内核（现有 `@deepseek-ai/dsh-workflow-ptc`） | `lib/presets/*.mjs`（由 `tools/build-presets.mjs` 从 `<id>/agent.cordis.yml` 生成） | 预设声明的解析基准是 profile 目录，相对 `./x.mjs` 不成立 |
| E3 | 热重载：稳定入口按「代」动态导入实现 | `lib/router-bootstrap*.mjs`、`lib/generation.mjs` | 代一变即新模块 URL，绕开 ESM 缓存 |
| E4 | 幂等注册（模块级引用计数 + 重名容忍） | `lib/index.mjs` | 冷/热两行并存时第二次注册不抛 Duplicate |

### preset router-standard（bootstrap / agent.cordis.yml）

| # | 定制 | 说明 |
|---|---|---|
| B1 | persona 双键（同段文案挂 `text` + `prefix`） | 内核按当期 schema 取用（现取 `prefix`） |
| B2 | `sessionEvents(session)` shim | Session 无 `.events`，此 shim 是唯一读口（`snapshotEvents()`） |
| B3 | 阶段 0 纳入 MCP 工具（codegraph_explore 紧跟 grep，wiki 两件随后，web_search 退最后） | 查已有知识三件套与检索工具同档 |
| B4 | engram 不接入（工具名 / 白名单 / memory-mute 均无；`categorizeDomain` 的 memory 分支是通用域分类，保留） | 预设不引用未安装插件的能力 |
| B5 | `skill` 进 META_TOOLS + GLOBAL_SAFE 常驻层 | 阶段 0–2 门控不清空宿主技能目录 |
| B6 | 委派会话豁免阶段门控：pre-step / applyStageRestrict / installMetaShim 三处 `parentSession` 守卫（连同 assemble 共四处，selftest 断言 >=4） | 子代理不被阶段记录摘掉执行工具 |
| B7 | 验证档 stage guide 的 shell 纪律行（v1.27） | >60s 命令走 `run_in_background:true` + `job_output`；探针自退出；未确认退出勿前台接 `\| tail` |
| B8 | 状态目录收口：stages/last-mount/bash-diag 写 `$DSH_HOME/router-presets/router-standard/`；新文件缺失时回退读旧布局 `$DSH_HOME/router-standard/`（只读不写） | `router-bootstrap-v34.mjs` | 顶层不再产生 `router-standard/` 目录；确认新路径就位后可删旧目录 |

### preset router-spec

| # | 定制 | 说明 |
|---|---|---|
| D1 | persona 双键 + sessionEvents shim（与 B1/B2 同款） | 同 B1/B2 |
| D2 | 读图判定用能力查询（`imageCapableRoute()` + `modlens_read_image` 桥回退） | 按模型声明的输入模态判定，不按名字猜 |

**selftest 纪律**：`router-bootstrap-v34.selftest.mjs` 必须原位运行保持 PASS。

**生成纪律**：`<id>/agent.cordis.yml` 是人读的源，内核不读它——
改完必须 `node tools/build-presets.mjs` 重新生成 `lib/presets/<id>.mjs`，两者一起提交。

## 三、安装

**preset 包（github 直装）**：

```powershell
dsh plugin --profile web add "github:Ztyss/dsh-routing-local#path:/preset"
# pnpm 走 git 拉私有仓（全局 schannel + gh 凭据），纯 JS 包、无 prepare，
# 不需要进 allowBuilds 白名单；重启 DSH 后生效
```

> **依赖形态**：manifest 里 preset 包写 `github:Ztyss/dsh-routing-local#path:/preset`。
> `#path:` 必须保留——它决定 pnpm 去仓库的哪个子目录取包。`dsh plugin --profile web add`
> 会把它规范化成 `git+https://…git`（丢 `#path:`），装完必须改回带 `#path:` 的写法再
> `pnpm install` 一次。缺 `#path:` 时 pnpm 从仓库根取包，而根目录没有 package.json，
> 装出来是空壳（包目录里没有 `lib/`）。

> **allowBuilds**：`~/.dsh/profiles/web/pnpm-workspace.yaml` 的 `allowBuilds` 放行
> `@ztyss/dsh-llm-provider`（git 直装包的构建白名单，新增 git 直装插件时照此追加）。
> preset 包无构建步骤，不需要追加。

**环境坑（实操验证）**：

1. Windows PowerShell 5.1：原生命令 stderr 走 `2>&1` 会被 `Stop` 方言抬成终止错误——原生调用放 `Continue` 护栏里，用 `$LASTEXITCODE` 判成败。
2. github 网络：git/OpenSSL 直连握手被重置——`http.sslBackend schannel` + `HTTP/1.1` 可通；release 下载用 `curl.exe --ssl-no-revoke`。
3. git 直装包的依赖树里若有未发布包（如 dsh-tools → dsh-type-meta 404），须保证包 manifest 不含会触发其安装的 peers（本仓 preset 包不声明 peerDependencies）。

## 四、升级与同步

### DSH 内核升级后

1. 记录新内核版本（`<DSH 安装位>\resources\app\node_modules\@deepseek-ai\dsh\package.json`）。
2. **先跑引用核验**：`cd <本仓>\preset; node tools/verify-presets.mjs` —— 65 条引用必须全 OK；
   出现 MISSING 就改 `tools/build-presets.mjs` 的 `mapName` 映射表与 `<id>/agent.cordis.yml` 的引用，
   再重跑生成。
3. 重跑 persona 双键验证：比对 `@deepseek-ai/dsh-persona` 的 Config schema 认哪个键（现取 `prefix`）；字段变了按 B1 手法补键。
4. 重跑 `session.events` 检查（`Select-String -Path "<本仓>\preset\router-*\*.mjs" -Pattern "session\??\.events"`），确认 `snapshotEvents()` 与 `header` 仍在。
5. 用内核 `agentPresets.list()` / `resolve()` 确认两个预设无 `broken`。
6. 重启 DSH，新会话选 Router Standard 实发一条消息确认全链路；历史会话（头部记 `agentPreset: router-standard`）也应能正常恢复。

### 上游更新后

1. **preset**：取上游 `preset/router-standard` 与 `preset/router-spec` → 对照第二节台账重放本地定制
   （B/C/D 组）→ 覆盖本仓 `preset/<id>/` → bump `?v=` → `node tools/build-presets.mjs` →
   原位 selftest + 包级 selftest → commit/push → 本机重跑 github 直装 → 重启 DSH → 新会话验证。

## 五、验证与卸载

```powershell
# preset 包进入组装树
# 用桌面版内核的 CLI：全局 npm 装的 dsh 缺桌面可选 bundle，--dump-config 会报
# cannot resolve profile bundle "@agents-anywhere/dsh-bridge-next"
node "<DSH 安装位>\resources\app\node_modules\@deepseek-ai\dsh\lib\bin.js" --profile web --dump-config |
  Select-String "dsh-router-presets"
# preset 包落地（profile node_modules）
Test-Path "$env:USERPROFILE\.dsh\profiles\web\node_modules\@dsh-external\dsh-router-presets\lib\index.mjs"
# 预设注册结果（包自带的装机自检：outcome / failed / roster）
Get-Content "$env:USERPROFILE\.dsh\router-presets\status.json"
# 预设内代码自检（本仓原位运行）
node "<本仓>\preset\router-standard\router-bootstrap-v34.selftest.mjs"
# 包级自检（幂等注册 / 代计数器 / 动态导入）
node "<本仓>\preset\tools\selftest.mjs"
```

卸载：

```powershell
dsh plugin --profile web remove @dsh-external/dsh-router-presets
```
