# dsh-routing-local 本地定制台账（injector + preset）

> **本文件是 dsh-routing-local 的唯一维护参考**，权威副本在本仓 `docs/`（本机不留拷贝）。
> 只记录现状：每一项定制是什么、在哪里、怎么装、怎么验证。
> 维护原则：**仓库是全部定制的唯一真源**；preset 改动必须 bump `?v=`、重跑 `tools/build-presets.mjs`
> 并跑 selftest；同步上游前先核对第二节台账是否已被上游吸收，避免重复打补丁。

- injector 源：https://github.com/yjh051108/dsh-super-injector （本仓 injector/ fork 自其 tag v0.3.5）
- 组织参照：https://github.com/yjh051108/dsh-routing-suite
- 本机安装：injector + preset 包（router-standard / router-spec），不含 graded
- 内核基线：`@deepseek-ai/dsh@0.1.7-rc.2`（DSH Desktop 2.0.15-next；上一基线 0.1.5-rc.2）

## 三、安装与打包

**injector（常规：github 直装）**：

```powershell
dsh plugin --profile web add "github:Ztyss/dsh-routing-local#path:injector"
# pnpm 走 git 拉私有仓（全局 schannel + gh 凭据），装时 prepare 自动构建 lib/
# 改了 host 侧代码 → 重启 DSH 后生效
```

**preset 包（常规：github 直装）**：

```powershell
dsh plugin --profile web add "github:Ztyss/dsh-routing-local#path:preset"
# 纯 JS 包、无 prepare，不需要进 allowBuilds 白名单；重启 DSH 后生效
```

> **锁文件口径**：add 之后 pnpm 会把 manifest 规范化成 `git+https://…git`（`#path:` 片段只落在
> `pnpm-lock.yaml`，与 commit 一起钉死）。日常 `pnpm install` 按锁文件解析没问题；
> **重装/换机器必须重跑上面这条 add 命令**——若删掉锁文件只靠 manifest 解析，会丢 path
> 装到仓库根（无 package.json，必炸）。

> **allowBuilds**：`~/.dsh/profiles/web/pnpm-workspace.yaml` 的 `allowBuilds` 已放行
> `@dsh-external/dsh-super-injector` 与 `@ztyss/dsh-llm-provider`（git 直装包的构建白名单，
> 新增 git 直装插件时照此追加）。preset 包无构建步骤，不需要追加。

**injector 需要发布 tgz 时（A2/A4 生效路径）**：

```powershell
cd <本仓>\injector
npm install
node scripts/prepare.mjs            # 构建 lib/（含构建机路径脱敏）
node scripts/local-pack.mjs 0.3.5 <输出目录>
dsh plugin --profile web add "@dsh-external/dsh-super-injector@file:<输出>/dsh-super-injector-0.3.5.tgz"
```

**tgz 格式约束**：`package/` 顶层目录；发布件剥 devDeps/peerDeps。

**环境坑（实操验证）**：

1. tar 两品种：bsdtar 不认 `--force-local`（Unknown option → exit 1），GNU tar 需要 `--force-local` 才吃 Windows 盘符路径——按 `tar --version` 选旗标。
2. Windows PowerShell 5.1：原生命令 stderr 走 `2>&1` 会被 `Stop` 方言抬成终止错误——原生调用放 `Continue` 护栏里，用 `$LASTEXITCODE` 判成败。
3. github 网络：git/OpenSSL 直连握手被重置——`http.sslBackend schannel` + `HTTP/1.1` 可通；release 下载用 `curl.exe --ssl-no-revoke`。
4. git 直装包的依赖树里若有未发布包（如 dsh-tools → dsh-type-meta 404），须保证包 manifest 不含会触发其安装的 peers（本仓已去 peers）。

## 四、升级与同步

### DSH 内核升级后

1. 记录新内核版本（`resources\app\node_modules\@deepseek-ai\dsh\package.json`）。
2. **先跑引用核验**：`cd <本仓>\preset; node tools/verify-presets.mjs` —— 65 条引用必须全 OK；
   出现 MISSING 就按 E2 手法把包名改到新名字（0.1.7 已把 `dsh-workflow-worker-thread` 换成 `dsh-workflow-ptc`）。
3. 重跑 persona 双键验证：比对 `@deepseek-ai/dsh-persona` 的 Config schema 还认不认 `prefix`；字段变了按 B1 手法加键。
4. 重跑 `session.events` 检查（`Select-String -Path "<本仓>\preset\router-*\*.mjs" -Pattern "session\??\.events"`），确认 `snapshotEvents()` 与 `header` 仍在。
5. 用内核 `agentPresets.list()` / `resolve()` 确认两个预设无 `broken`（旧写法 `discoverPresets` 在 0.1.7 已不存在）。
6. 重启 DSH，新会话选 Router Standard 实发一条消息确认全链路；旧会话（历史头记 `agentPreset: router-standard`）也应能正常恢复。

### 上游更新后

1. **preset**：取上游 `preset/router-standard` 与 `preset/router-spec` → 对照第二节台账重放本地定制
   （B/C/D 组）→ 覆盖本仓 `preset/<id>/` → bump `?v=` → `node tools/build-presets.mjs` →
   双 selftest + 包级 selftest → commit/push → 本机重跑 github 直装 → 重启 DSH → 新会话验证。
   （0.1.7 起不再往 `~/.dsh/.agent-presets/` 平铺同步，那份目录已退役。）
2. **injector**：取上游新 release 源码覆盖本仓 `injector/` → 对照 A1/A3 是否已被吸收（未吸收则重放）→ commit/push → 本机重跑 github 直装 → 重启 DSH。

## 五、验证与卸载

```powershell
# 注入器进入组装树
dsh --profile web --dump-config | Select-String "dsh-super-injector"
# preset 包落地（profile node_modules）
Test-Path "$env:USERPROFILE\.dsh\profiles\web\node_modules\@dsh-external\dsh-router-presets\lib\index.mjs"
# 预设注册结果（包自带的装机自检：outcome / failed / roster）
Get-Content "$env:USERPROFILE\.dsh\router-presets\status.json"
# 预设内代码自检（本仓原位运行）
node "<本仓>\preset\router-standard\router-bootstrap-v34.selftest.mjs"
node "<本仓>\preset\router-standard\gitbash-executor.selftest.mjs"
# 包级自检（幂等注册 / 代计数器 / 动态导入）
node "<本仓>\preset\tools\selftest.mjs"
```

卸载：

```powershell
dsh plugin --profile web remove @dsh-external/dsh-router-presets
dsh plugin --profile web remove @dsh-external/dsh-super-injector
# 旧目录制 preset（0.1.7 起内核不再读取，仅备份）
Remove-Item "$env:USERPROFILE\.dsh\.agent-presets\router-standard" -Recurse
Remove-Item "$env:USERPROFILE\.dsh\.agent-presets\router-spec" -Recurse
```
